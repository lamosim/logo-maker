# logo-maker

This folder turns a venture into a production-ready logo package. The `logomaker` CLI (Python, run with uv) does every deterministic step: brand state, geometry, fonts, rendering, audits, sheets, exports. The `logo` skill in `.claude/skills/logo/` runs the conversation and makes every design judgment.

## Routing

- Always use the `logo` skill for any request about a logo, mark, wordmark, brand identity, naming a venture, favicons, app icons, brand assets, or continuing a brand in `brands/`.

## Rules

- Never hand-write SVG, PNG, PDF or ICO deliverables. Write concept modules (`concept.py`) and run the CLI.
- Never edit `registry/` or any `brand.json` directly; use the `uv run logomaker brand` commands.
- Never read `.env` if one appears; `.claude/settings.json` denies it.
- Every CLI command prints one JSON object on stdout; read it instead of parsing logs. Logs go to stderr. Exit codes: 0 ok, 2 rule or input violation, 3 external failure (Chrome, network, missing font), 4 verification failure (`package verify`, or a blank render in `package build`).
- Run `uv run logomaker package build` with the Bash timeout set to 300000. Every other command but `fonts fetch`, which depends on the network, finishes within about a minute (`names check` stops starting lookups after 45 s).
- Never run `playwright install`; rendering uses the installed Google Chrome.
- Read every critique sheet and owner sheet PNG with the Read tool before deciding about a concept.

## Where things live

- Brands: `brands/<slug>/` with `brand.json`, `brief.*`, `naming.md`, `strategy.*`, `territories/`, `concepts/`, `sheets/`, `final/`, `package/`, and `inspiration/` for reference images the owner drops in.
- Registry: `registry/brands.json` and the generated `registry/INDEX.md`.
- Knowledge base: `.claude/skills/logo/reference/`; full research reports in `docs/research/`. Its `cliches.md` and `fonts.md` are generated by `uv run python scripts/build_reference.py` from `assets/cliches.json`, `assets/fonts/catalog.json` and `scripts/templates/fonts.md`; never edit them by hand.
- Code: `src/logomaker/`; templates: `templates/`; fonts cache and catalogue: `assets/fonts/`; cliché data: `assets/cliches.json`.
- Example brand: `docs/examples/keystone/`.

## Tests

- Fast suite, no Chrome and no network: `uv run pytest -m "not render and not live"`
- Render suite, uses the installed Chrome: `uv run pytest -m render`
- Live suite, needs the network: `uv run pytest -m live`
